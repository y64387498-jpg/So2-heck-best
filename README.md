# So2 Head Studio PRO

A Java Android WebView companion project with a responsive HTML/CSS/JavaScript interface and GitHub Actions APK build.

## Features
- PRO dark/neon interface
- Adjustable sample-avatar head scale and presets
- START launches Standoff 2 when installed
- Bundled high-resolution visual texture
- GitHub Actions workflow for debug APK

## Important
The head scale affects only the sample character preview in this companion app. It does not alter Standoff 2 game assets, hitboxes, memory, or online gameplay.

## Build
Upload this repository to GitHub. Open Actions and run **Build So2 Head Studio PRO APK**. Download the artifact `So2HeadStudioPRO-debug`.

Package ID used to launch the game: `com.axlebolt.standoff2`.
